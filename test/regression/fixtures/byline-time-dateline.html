A debugging manifesto

Abhijeet Bhale Posted on Jan 6

When you run into a bug, the natural instinct is to try to fix it as fast as possible, but it is generally more effective to leave the bug in place and understand it first.

Sometimes I get really demoralized when debugging and it feels like I will never make progress, so I remind myself that I have fixed a lot of bugs before and will fix this one too.
