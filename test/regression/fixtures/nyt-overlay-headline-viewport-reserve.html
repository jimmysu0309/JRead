Overlay Headline Viewport Reserve Test Article

Thanks to an assist from structural signals, the reader mode is set to release the byline from a full page of reserved blank space below the summary paragraph.

By Regression Spec

The three-decade run of this fixture began when a full-bleed hero template stacked multiple viewport-height wrappers on top of each other, each one reserving an entire screen of vertical space for a cinemagraph that never participates in normal flow layout at reader card widths.

In the aftermath, the absolute media layer carried its own duplicate headline element, which routed the cleanup through the title overlay branch instead of the hero media branch, so the containing block height reset never had a chance to run on any of the reserving ancestors.

Again and again, the byline appeared a full viewport below the summary text, until the ancestor chain flattening pass measured each wrapper against the viewport height signature and collapsed the stylesheet reservations back to content-driven heights.
