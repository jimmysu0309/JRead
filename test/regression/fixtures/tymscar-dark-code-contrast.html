Running a local LLM on a V100

NixOS made most of this straightforward. Here is the key configuration for getting the driver and kernel right, including the legacy nvidia package selection and the xserver video driver list that the V100 requires.

boot.kernelPackages = pkgs.linuxPackages_6_6;
services.xserver.enable = true;
services.xserver.videoDrivers = [ "nvidia" ];

And for loading CUDA 12.2 from an older nixpkgs since the current one only ships 12.6 and newer versions that are not compatible with the V100 compute capability.

To get the model running I had to pin llama.cpp to a specific commit and patch the CUDA architecture list so that compute capability 7.0 was included in the build flags for both cards.

The full configuration is in this commit on my dotfiles repo if you want to reproduce the setup on your own machine.

The important thing is: it works. Both GPUs show up, CUDA is functional, and NixOS keeps the whole configuration declarative so the machine can be rebuilt from scratch at any time.
