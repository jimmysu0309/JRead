How LLMs Actually Work

Large language models have become ubiquitous, but the mechanics underneath remain opaque to most people who use them every day. In this article we trace the full pipeline from raw text to generated tokens, building intuition for what each stage actually computes.

We start with tokenization, then move through embeddings, attention, the feed-forward network, and the residual stream that ties everything together into a coherent computation.

Tokenization

Before a model can process text it must first break that text into discrete units called tokens. These are not always whole words — common subword fragments are merged during training to balance vocabulary size against sequence length.

Attention

The attention mechanism lets each token gather information from every other token in the sequence, weighting their contributions by learned relevance scores. This is the core innovation that made transformers so effective at modelling long-range dependencies in language.
