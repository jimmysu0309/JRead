Array.prototype.at()

Description

The at() method is equivalent to the bracket notation when index is a non-negative integer. For example, both array[0] and array.at(0) return the first item, and array[array.length - 1] and array.at(-1) return the last item. When counting elements from the end of the array with a negative index, you cannot use array[-1] like you may in Python or R, because all values inside the square brackets are treated literally as string properties, so you end up reading array["-1"], which is just a normal string property instead of an array index.

Syntax

Return the last value of an array

const cart = ['apple', 'banana', 'pear'];
console.log(cart.at(-1)); // 'pear'
