# JRead

純閱讀模式的 Chrome / Firefox / Safari 擴充功能。一鍵隱藏廣告、側邊欄、彈窗與浮動元素，把主文抽出來、套上乾淨排版，讓網頁回到「只有文字與圖片」的閱讀狀態。

適用於新聞網站、部落格平台、Wikipedia、技術文件等以文章為主的頁面。偵測不到主文時會直接不動作，不會硬套版型破壞原頁面。

**目前版本與更新紀錄**：見 [GitHub Releases](https://github.com/jimmysu0309/JRead/releases)。

## 功能簡介

JRead 圍繞三件事：**找出主文**、**清掉雜訊**、**排得好讀**。在這之上再疊加翻頁、閱讀位置記憶、稍後閱讀服務整合等閱讀習慣相關的功能，桌面與行動裝置（含 iOS Safari）共用同一套設定。

### 閱讀模式核心

- **主文偵測**：依序嘗試 `<article>`、Schema.org 標記、內容密度啟發式，找出頁面真正的文章區塊
- **一鍵切換**：從工具列圖示選單、懸浮按鈕、快速鍵或三指輕點進出閱讀模式
- **自動啟動網域**：把常讀的網站加入清單，頁面載入就自動進入閱讀模式；可在工具列圖示選單勾「此網域自動啟動」，或在設定頁一行一個網域管理
- **乾淨排版**：可調字體、字級、字重（細／中／粗）、行高與版心寬度；版心自我檢查會確保內文、標題、分類列都撐滿設定寬度，不被原站 wrapper 的內距夾窄；引言區塊整塊內縮、保留原站設計，原站沒畫引言框或邊線在目前主題下看不清楚時補上主題色左邊線，中文引言不套斜體
- **英文字型自選**：字體選襯線或無襯線時，可另外指定英文與數字使用哪支拉丁字型，中文維持原本的襯線／無襯線渲染，兩種模式各自記住選擇；除系統字外另內附四支可變字型（Source Serif、Piazzolla、Public Sans、Source Sans），跨平台（含 iOS）皆可用
- **中英文間自動補空白**：中文與英文、數字相鄰處自動補空白，中文旁的半形標點轉全形；程式碼與連結不受影響（預設開啟，可在設定關閉）

### 雜訊處理

- **雜訊隱藏**：自動移除廣告、sticky header、彈窗、相關文章列表等干擾元素
- **收合內容自動攤開**：百科 infobox 的可展開清單、accordion 面板、原生 `<details>` 這類站方預設折起來的內容會自動攤開——閱讀模式會清掉頁面上的按鈕，不攤開的話那些內容就再也點不出來。文末的導覽連結表不在此列，仍維持收合
- **YouTube 影院／無邊模式**：在 YouTube 影片頁，影院模式把影片放大置中、四周變黑並隱藏留言與推薦清單（與切換閱讀模式共用 ⌥R）；無邊模式讓影片撐滿整個視窗、視窗高度自動符合影片比例（預設 ⌥Y）。按 ESC 退出
- **X（Twitter）串文**：在單則貼文頁啟動閱讀模式，會把同一位作者的連續貼文合成一篇文章來讀，其他人的回覆不列入
- **編輯模式**：手動清掉 cleaner 漏網的雜訊段落，讓文章在**列印**或**送到稍後閱讀服務**時更乾淨。閱讀模式下框選要移除的段落，點一下即隱藏，誤刪可復原或按 Cmd/Ctrl+Z；移除只在當次有效（退出或重整即還原），被移除的段落不會出現在列印結果，也不會被送進稍後閱讀服務

### 閱讀體驗

- **主題**：亮／暗／米色／灰／夜藍五種配色（預設灰色），閱讀區配色對齊 Apple Books
- **左右對齊**：關（全部靠左，預設）／中文（只對中文段落左右對齊）／全部（英文段落也對齊並自動斷字）
- **設定檔**：把工具列圖示選單裡那組版面設定（主題、字級、標題字級、行距、段落間距、版心寬度、字重、左右對齊、中英文字型、翻頁模式）存成具名設定檔，最多 5 組，一鍵切換。每台裝置各自選用哪一組（設定檔清單會同步，選擇不會，兩台電腦可以用不同的設定檔）；套用後調整任一欄位會停在該設定檔並標示「已修改」，按「更新」就存回原設定檔。懸浮按鈕長按選單也能直接切換
- **閱讀進度條**：捲動模式下頂端一條細進度線。它疊在捲動的內容上，底下可能是任何顏色的圖片或區塊，所以純色細線在同色系背景上會看不見。預設是**漸層**條——條子自身同時含亮青與藍紫，任何底色最多吃掉一端；也可在設定改回純色細線，或選描邊（深底靠白邊、淺底靠黑邊）、描邊加軌道、加高加投影
- **兩種閱讀方式（二選一）**：預設是**捲動模式**（一般垂直捲動），可在設定切換成**翻頁模式**（或按快速鍵 ⌥P；閱讀模式未啟動時按 ⌥P 會直接以翻頁模式進入）——像電子書一樣左右翻頁，手機左右滑動、桌面用方向鍵或滾輪，圖片自動縮放至單頁內；底部頁碼可當快速捲動器，按住左右拖曳即可跳頁，拖動時顯示進度條與每頁的觸覺回饋
- **圖片預覽**：閱讀模式中點內文圖片，開全螢幕預覽——大圖縮到螢幕內、小圖維持原尺寸不放大，並自動換成最大可用的原圖；點背景、按 Esc 或在手機上往下滑即可關閉，回到原本的閱讀位置。預覽中的圖片可直接用瀏覽器的右鍵／長按選單儲存或複製。頭像與圖示（任一邊小於 100px）不觸發，連到另一篇文章的圖片照舊開連結；捲動模式與翻頁模式都適用
- **段落焦點捲動（僅捲動模式）**：左側指示條標記目前段落，按 Space 跳到下一段，段落低於顯示門檻時平滑捲回畫面上方（門檻可調）；翻頁模式下不適用
- **滑鼠閒置時隱藏游標**：閱讀模式下滑鼠停著不動 2 秒就把游標藏起來，移動或點擊立刻回來；捲動不算移動，所以用滾輪或 Space 讀的時候游標會一直隱藏（可在設定關閉，觸控裝置不受影響）
- **閱讀位置記憶**：文章看到一半離開（退出閱讀模式、關分頁、重啟瀏覽器）會記住位置——捲動模式記段落、翻頁模式記頁數，效期內重新進入自動回到上次位置（效期可調，預設 3 天、最長 7 天、0 為停用）
- **點連結延續閱讀模式**：閱讀模式下點文內連結，目標頁（原分頁或新分頁）會自動進入閱讀模式；自己在網址列輸入網址不受影響（預設開啟，可在設定關閉）

### 稍後閱讀服務整合

- **JReader、Readwise Reader 或 Instapaper（三選一）**：在設定頁「稍後閱讀」分頁選定服務後（預設 JReader；網址沒寫 https:// 會自動補上），可把 JRead 處理過的乾淨主文一鍵送出，繞過原站解析問題；Instapaper 走官方 Full API（xAuth，填一次 email／密碼換存取權杖，密碼用完即丟），Readwise 走 access token，JReader（自架的 Readwise 相容後端）填網址與 token。JReader 的文章清單、畫重點、閱讀進度與 Readwise 相同
- **進入 Reader**：直接在新分頁列出所選服務的最新文章，點進去用 JRead 原本的閱讀版型呈現，主題／字型／字級／翻頁全部沿用同一套控制，也會記住閱讀位置。文章清單上左滑封存、右滑加入 Later（Instapaper 為加星）；電腦上對文章按右鍵也有同樣兩個選項。頂端分頁依服務切換：Readwise 為 Inbox／Later／JRead（在 Readwise 標記為 JRead 的文章），Instapaper 為未讀／已加星／封存。卡片會顯示兩行摘要與日期；按 J／K 上下選文章、Enter 打開、E 封存、L 加入 Later，按 V 或右鍵「開啟原始網址」在新分頁開原文，按 ? 看這一頁能用的快速鍵
- **JReader 書庫工具**：儲存服務選 JReader 時，文章清單多了 Inbox／Later／Archive／Progress（讀到一半的文章）分頁與垃圾桶（刪除後 30 天內可還原）；右下角的放大鏡（或按 /）可搜尋全部文章、貼網址存新文章、依標籤篩選，也能多選文章一次搬移、加標籤或刪除（貼網址時沒寫 https:// 會自動補上）。讀文章時按 I 打開文章資訊：來源與作者（點了看同一來源的其他文章）、閱讀時間、資料夾、標籤、筆記、重點清單、摘要與公開分享連結。按 D 刪除（清單上選到的文章或正在讀的這篇，再按一次 D 確認）；在電腦上讀文章時，滑鼠一動左上角就會浮現「← 列表」可回文章清單。已裝擴充的瀏覽器打開 JReader 網頁版時，擴充會自動讓位，網頁版直接沿用擴充的排版設定（帳號與金鑰不會交給網頁）
- **在 JReader 畫重點（Readwise）**：在「進入 Reader」打開的 Readwise 文章裡選取文字，點「畫重點」或按 H，重點會直接存回 Readwise（可跨段落）；在 Readwise 網站或 App 畫過的重點也會標出來，點一下重點可刪除。Instapaper 不支援
- **JReader 跨裝置接續閱讀、按 E 封存**：JReader 會把你讀到的位置存回 Readwise，在另一台裝置的 JReader 打開同一篇會接著讀；往回重讀的位置也會跟著走。各裝置排版不同，位置是近似值；沒有別處的新進度時以這台記的位置為準。讀文章時按 E 可直接封存並回到文章清單（Readwise 與 Instapaper 皆可；進度接續僅 Readwise）
- **iPhone / iPad App 內建 JReader**：打開 JRead App 按「啟用 JReader」，之後每次開 App 就直接進文章清單，不必經過 Safari。主題、字型、翻頁與 Readwise／Instapaper 帳號設定跟 Safari 中的 JRead 自動同步（在 Safari 改設定，回到 App 就套用；讀文章時點 J 圖示開選單，選「功能選單」也能直接改主題、字型與翻頁，選「設定」開完整設定頁，可改稍後閱讀服務、閱讀位置記憶等，改了會同步回 Safari；文章清單左下角也有 J 圖示可開設定）。讀文章時狀態列與 J 圖示會自動隱藏，點一下畫面就叫出來；從螢幕左緣往右滑就回到文章清單；文章清單往下拉即可更新。App 主畫面圖示可在設定頁「App 圖示」切換藍底白字或白底黑字，下次開 App 時套用
- **從 Safari 分享面板送出（iPhone / iPad）**：在 Safari 按分享、點 JRead，就把眼前這頁送到所選的稍後閱讀服務，不必先進閱讀模式。送出的就是你看到的版本：翻譯後的譯文、清掉的雜訊、編輯模式移除的段落都一樣。只在 Safari 出現（其他 App 分享只有網址，拿不到頁面內容）；點了直接送，完成後自動關閉。需要先在 Safari 允許 JRead 存取該網站
- **JReader 本機快取**：文章清單與讀過的文章存在本機，重新整理或換頁回來立刻顯示、不必每次重新下載；離線時也看得到上次的清單與讀過的文章（App 預先下載的文章連圖都能離線看，其他情況的圖片仍需連網）。用 JReader 服務時，iPhone / iPad App 打開文章清單會在背景先下載 Inbox 與 Later 各前 20 篇，沒開過的也能離線讀，文章裡的圖也一起存。文章快取上限 300 MB，超過會刪掉最久沒開的；也可在設定頁「本機快取」一鍵清除。單篇文章內容不對或想拿服務端的最新版時，點 J 圖示選「重新抓取文章」，會丟掉這篇的本機快取、重新從稍後閱讀服務下載
- **在 Readwise Reader 網頁畫重點**：直接在 Readwise Reader 的文件頁開閱讀模式時，選取文字仍會出現 Reader 自己的工具列，點一下或按 H 就能畫重點（捲動與翻頁模式皆可）；畫過的重點也會保留原本的底色（其他用同類標註工具的網站同樣適用）
- **送出摘要**：選用 Google Gemini Flash Lite，在送出時一併產生文章摘要（Readwise 取代其內建英文摘要、Instapaper 放進項目描述），需在設定填入自己的 Gemini API key，兩個服務共用此設定

### 操作方式

- **懸浮按鈕**：頁面邊緣常駐一顆小圖示，短按切換閱讀模式、長按開選單、拖曳可換到左右緣與上下位置；可在設定調整透明度與尺寸，或關閉
- **三指輕點**：觸控裝置三指輕點頁面即可進出閱讀模式（預設關閉，可在設定開啟）
- **自訂快速鍵**：內建預設鍵為 ⌥R（切換閱讀模式）、⌥⇧R（送到稍後閱讀服務）、⌥Y（YouTube 無邊模式）、⌥P（翻頁模式）；另可為「切換閱讀模式／送出到稍後閱讀服務／YouTube 無邊模式／切換翻頁模式」錄製組合鍵；Safari（含 iPad 外接鍵盤）沒有瀏覽器層的改鍵入口，這裡是唯一通道，Chrome 也通用
- **匯出／匯入設定**：在設定頁「進階」分頁把偏好設定、設定檔、自動啟動網域與自訂快速鍵存成 JSON 檔，換電腦時匯入即可；檔案不含任何 API key、token、JReader 網址與 Instapaper 帳號，匯入也不會動到這些憑證。iPhone / iPad（Safari 與 JRead App）按「匯出」會開分享面板，選「儲存到檔案」即可
- **回復預設**：一鍵把所有設定還原成預設值（需二次確認），會一併清掉已儲存的設定檔、自動啟動網域清單與自訂快速鍵且無法復原，但會保留 Readwise／JReader／Gemini 的憑證與 Instapaper 連結

## 開發

- **原始碼**：`jread/` 即完整的 extension 本體，無 build step、無壓縮混淆，直接載入未封裝資料夾即可跑
- **Firefox 版重建**：見 [BUILD.md](BUILD.md)（單一 `jq` 指令改寫 manifest，其餘檔案逐位元組相同）
- **更新紀錄**：見 [GitHub Releases](https://github.com/jimmysu0309/JRead/releases)
- **完整內部規格與變更紀錄不在本 repo**：那兩份文件同時記錄了大量開發過程與判斷脈絡，作者選擇不公開
- **維護者在新環境接開發環境**：測試套件與內部文件住在兩個私有 repo，接法見 [docs/DEV-SETUP.md](docs/DEV-SETUP.md)
