JRead 偏好設定

v

快速鍵

點欄位後直接按下想要的組合鍵（需包含 ⌥ Option 或 ⌃ Control，按 ESC 取消錄製）。自訂鍵由 JRead 在頁面內攔截；內建預設鍵仍然有效；位址列輸入中時自訂鍵收不到按鍵（預設鍵不受此限）

點欄位後直接按下想要的組合鍵（Safari 需用 ⌃ Control 組合，按 ESC 取消錄製）。⌥ Option／⌘ Command 組合會被 Safari 系統層攔截、傳不到網頁，自訂鍵一定要含 ⌃ Control。iOS / iPadOS 沒有瀏覽器層快速鍵設定，外接鍵盤請在這裡自訂。內建預設鍵仍然有效

自動啟動網域

符合以下網域時，頁面載入即自動進入閱讀模式。一行一個網域。abc.com 會涵蓋 www.abc.com 與所有子網域；www.abc.com 只匹配 www.abc.com 本身（不含 123.abc.com）。也可在 popup 用「此網域自動啟動」開關快速加入目前網域

YouTube 模式

在 YouTube 影片頁開啟 JRead 視窗時，除了一般的「切換閱讀模式」按鈕之外，還會多出兩種觀影專用模式。請依場景擇一使用，啟動後按 ESC 即可退出。影院模式跟一般閱讀模式共用 Alt+R 快速鍵——在 YouTube 影片頁按下會自動切到影院模式；無邊模式內建預設鍵 Alt+Y，也可在上方「快速鍵」區自訂（Chrome 亦可到 chrome://extensions/shortcuts 設瀏覽器層快速鍵）

影院模式

把影片放大置中、四周變黑底，並把上方搜尋列、留言、影片描述、推薦清單、片尾彈出卡片等干擾元素全部隱藏。瀏覽器視窗大小不變

無邊模式

影片直接撐滿整個瀏覽器視窗、所有 YouTube 介面隱藏，視窗高度也會自動調整成符合影片比例——最沉浸的觀影體驗

Readwise Reader 整合

在 popup 點「送到 Readwise Reader」會把 JRead 處理過的乾淨內容透過 Readwise API 儲存。 Token 從 readwise.io/access_token 取得，僅儲存在你本機的瀏覽器同步空間（chrome.storage.sync），不會上傳到任何 JRead 伺服器
