為什麼做 JRead？

不少閱讀器會把你開啟的文章送到自家伺服器處理。JRead 的做法相反，所有處理都留在你的瀏覽器

JRead 把「乾淨閱讀」和「隱私」綁在一起：

全本機處理：主文偵測、雜訊清除、排版全部在你的瀏覽器跑，頁面內容不上傳任何伺服器
設定留在本地：偏好只存在你的瀏覽器，跨裝置同步走瀏覽器內建機制，不經第三方
開放原始碼：程式碼完全公開，任何人都能檢視，確認沒有後門
選用整合才連網：只有你主動送到 Readwise / Instapaper 或開啟 Gemini 摘要時才連外，且用你自己的帳號與 API key

Essay · 12 min read
論專注：為什麼我們越來越讀不完一篇長文
By 林書宇 — Mar 2026

一篇文章常被廣告、側欄和彈窗包圍

JRead 把它們移開，只留下文字、段落與留白

同一個頁面，雜訊清掉、排版重整，讀起來像一本書

功能特色

智慧主文偵測

用 article 標籤、Schema.org、內容密度啟發式找出主文；找不到就不動原頁，不亂套排版

乾淨排版

可選襯線或無襯線、三段字重、可調行高與版心寬度，中英文都讀得舒服

四種閱讀主題

亮、暗、米色、灰隨時切換，配色對齊 Apple Books，OLED 夜間友善

英文字型自選

可單獨指定英文 / 數字用哪支拉丁字型，中文照襯線 / 無襯線渲染；內附多支跨平台可變字型

雜訊隱藏

廣告、sticky header、彈窗、相關文章列表通通清掉，全是結構通則、非站點特判

收合內容自動攤開

百科 infobox 的可展開清單、accordion 面板、原生 details 區塊自動攤開——閱讀模式會清掉頁面上的按鈕，不攤開就再也點不出來；文末導覽連結表仍維持收合

編輯模式

cleaner 漏掉的雜訊段落以虛線框標出，點一下即移除，誤刪可復原或 Cmd/Ctrl+Z；讓文章在列印或送稍後閱讀服務時更乾淨

段落焦點捲動

捲動模式下左側指示條標記目前段落，按 Space 跳下一段、低於門檻自動平滑捲回，仿 Readwise Reader

閒置隱藏游標

閱讀模式下滑鼠停著不動 2 秒就藏起游標，移動或點擊立刻回來；捲動不算移動，用滾輪或 Space 讀時游標一直隱藏

翻頁模式

捲動 / 翻頁二選一：翻頁像電子書一樣左右翻頁——手機滑動、桌面方向鍵或滾輪，底部頁碼可當快速捲動器

懸浮按鈕

頁面邊緣常駐小圖示，短按切換閱讀模式、長按開選單、可拖曳換到左右緣與上下位置

閱讀位置記憶

看到一半離開，效期內重新進入閱讀模式自動回到上次位置——捲動模式記段落、翻頁模式記頁數

送到稍後閱讀服務

把處理過的乾淨主文一鍵送進 Readwise Reader 或 Instapaper（二擇一），繞過原站 parser 問題；可選用 Gemini 自動產生摘要

進入 Reader

在新分頁列出所選服務的最新文章，點進去用 JRead 的閱讀版型呈現，主題 / 字型 / 字級 / 翻頁全部沿用，也記住閱讀位置

自訂快速鍵

可為切換閱讀模式 / 送到稍後閱讀服務 / YouTube 無邊模式錄製自訂組合鍵，Chrome 與 Safari 皆通用

三步驟，開始乾淨閱讀

1

下載並載入

從 GitHub 下載 .zip 解壓，開啟 Chrome 前往 chrome://extensions/，打開右上角「開發人員模式」，點「載入未封裝項目」選擇 jread 資料夾

2

打開任一文章

新聞、部落格、論文、Medium、Substack，任何以文字為主的頁面都可以

3

啟動閱讀模式

點工具列的 JRead 圖示，或用懸浮按鈕、自訂快速鍵，雜訊立刻消失
