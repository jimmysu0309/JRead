為什麼做 JRead？

閱讀工具不該變成另一個盯著你的東西。JRead 把「乾淨閱讀」和「隱私」綁在一起——主文偵測、雜訊清除、排版全部在你的瀏覽器本機跑

全本機處理：頁面內容不上傳任何伺服器
設定留在本地：偏好只存在你的瀏覽器，跨裝置同步走瀏覽器內建機制
開放原始碼：程式碼完全公開，任何人都能檢視，確認沒有後門
選用整合才連網：只有你主動送到 Readwise 或開啟 Gemini 摘要時才連外，且用你自己的帳號與 API key

三步驟，開始乾淨閱讀

1

安裝

從 GitHub 下載 zip 解壓，到 chrome://extensions/ 開啟開發人員模式，點「載入未封裝項目」選 jread 資料夾

~ 1 min
2

打開任一文章

新聞、部落格、論文、Medium、Substack，任何以文字為主的頁面

any article
3

啟動閱讀模式

點工具列的 J 圖示，或用懸浮按鈕、自訂快速鍵，雜訊立刻消失

shortcut ⌥ R
